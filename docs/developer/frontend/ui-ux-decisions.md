# UI/UX Decisions

## Visual Indicators
- Green: Running/healthy
- Red: Stopped/error
- Yellow: Warning/attention
- Status icons for containers, scripts, and system health

## Layout
- Dashboard grid with draggable/resizable modules
- Sidebar for navigation
- Top bar for status and settings

## User Interactions
- Confirmation dialogs for critical actions (shutdown, reboot)
- Tooltips for icons and buttons
- Inline error messages for API failures
- Loading spinners for async operations

## Accessibility
- Keyboard navigation for all controls
- Sufficient color contrast
- Responsive design for desktop/tablet

## Refresh & Feedback
- Auto-refresh with configurable interval
- Manual refresh buttons on modules
- Last updated timestamps
